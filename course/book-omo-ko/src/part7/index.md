# 제7부: 무엇을 추출해 자기 플러그인으로 옮길 것인가

이 책의 마지막 질문은 오마오를 어떻게 따라 만들 것인가가 아니다. 무엇을 가져가고 무엇을 버릴 것인가다. 모든 프로젝트가 11개 에이전트, 52개 훅, 26개 도구를 필요로 하지는 않는다. 하지만 오마오가 보여 주는 경계 설정, 설정 병합, 확장 계약 분리, 장기 실행 관리, fallback 분리는 다른 플러그인에도 옮길 수 있다.

이 부는 오마오를 설계 청사진으로 바꾼다. 기능 수를 복제하지 말고, 기능이 들어갈 슬롯을 먼저 정한다. 훅을 늘리기 전에 훅 티어를 정하고, 에이전트를 늘리기 전에 모델 요구사항과 위임 계약을 정한다.

## 핵심 질문

- 어떤 기능은 OpenCode native에 맡길 것인가
- 어떤 기능은 config handler에서 합성할 것인가
- 어떤 기능은 tool로 드러내고 어떤 기능은 hook으로 숨길 것인가
- 어떤 실패는 자동 복구하고 어떤 실패는 사용자에게 알려야 하는가
- 어떤 호환성은 유지하고 어떤 호환성은 잘라낼 것인가
