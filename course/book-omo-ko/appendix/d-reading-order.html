부록 D: 추천 독서 경로

온라인판은 책의 질문과 해석 순서를 유지하면서 현재 fork의 실제 소스 경로와 링크를 함께 제공합니다.

현재 fork 기준 보정

이 온라인판은 원고의 관점과 장 구성을 유지하지만, 현재 speaky-oh-my-openagent 포크의 리팩터링을 기준으로 소스 경로를 보정합니다. 원고의 오래된 src/... 참조는 가능한 경우 packages/omo-opencode/src/...로 해석합니다.

루트 src/는 더 이상 canonical source tree가 아니며, OpenCode 어댑터는 packages/omo-opencode/src/, Codex Light edition은 packages/omo-codex/, 공유 core는 packages/*-core/에 분리되어 있습니다.

1. 플러그인 구조를 빨리 잡는 경로

1장 -> 2장 -> 3장 -> 4장 -> 10장 -> 19장 -> 29장

이 경로는 오마오의 entry point, manager, tool registry, config handler, hook tier를 빠르게 훑는다.

2. 멀티 에이전트 운영을 보는 경로

5장 -> 6장 -> 7장 -> 8장 -> 9장 -> 21장 -> 22장

설정이 agent와 model policy로 바뀌고, category 위임과 continuation이 장기 실행으로 이어지는 흐름을 본다.

3. Claude Code 호환성을 보는 경로

14장 -> 16장 -> 17장 -> 18장 -> 25장 -> 27장

agent, command, MCP, skill loader가 Claude Code 자산을 OpenCode config로 번역하는 방식을 본다.

4. 안전성과 복구를 보는 경로

19장 -> 20장 -> 21장 -> 22장 -> 23장 -> 27장

guardrail, hashline edit, background task, fallback, 관찰성, 설정 진단을 묶어 본다.

5. 배포와 운영 표면을 보는 경로

13장 -> 23장 -> 26장 -> 27장 -> 28장

CLI, log, telemetry, schema, platform binary까지 제품화 경로를 본다.

6. 시간이 없을 때 보는 최소 경로

서문 -> 1장 -> 2장 -> 10장 -> 19장 -> 30장

이 경로만 읽어도 오마오를 "OpenCode 위의 플러그인 하니스"로 이해하는 데 필요한 핵심 질문은 잡힌다.
